# Twig Server

Welcome! This is the server that hosts commits/branches/objects and also the client for you to access them online. It uses [Supabase](https://supabase.com/) tables and [Microsoft Azure Blob Storage](https://azure.microsoft.com/en-us/products/storage/blobs). 

You can host this yourself by configuring the `.env.example`
